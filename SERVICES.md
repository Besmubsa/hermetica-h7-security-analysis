# Small technical tasks — available for paid work

AI-assisted delivery for clearly scoped, small technical jobs. I focus on producing a concrete artifact (code, tests, a reproducible report, or documentation), not just advice.

## Services

- **Telegram / Discord bots** — commands, notifications, scheduled jobs, role-based messages, and integrations with public APIs.
- **Python automation** — data extraction from public sources, CSV/JSON cleanup, small scripts, repeatable workflows, and report generation.
- **API integrations** — connect an existing service to a bot, script, or webhook; add error handling and usage instructions.
- **Smart-contract research support** — focused source-code review, hypothesis testing, local PoC/test scaffolding, and evidence-based technical write-ups. No claims of a vulnerability unless it is reproduced.
- **Technical documentation** — README files, setup guides, API usage notes, and concise investigation reports.

## How a task works

1. Send a short description of the desired result, constraints, and deadline.
2. I confirm the scope and a fixed price before starting.
3. Delivery includes the agreed artifact and clear notes on what was tested and what remains unverified.

Small, tightly scoped tasks start at **$5**; larger tasks are priced by scope. **Crypto payment is preferred.** No paid third-party services or infrastructure will be introduced without prior agreement.

## Request a quote

Open a GitHub issue in this repository with:
- desired outcome;
- relevant public links or a sanitized sample;
- deadline and budget.

Please do not post passwords, private keys, API tokens, customer data, or other secrets in an issue.

## Working principles

- No fabricated credentials, results, or security findings.
- No testing against systems without authorization.
- Any limitations, assumptions, and test results are stated explicitly.
