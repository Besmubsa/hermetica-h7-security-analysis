## Почему подавать нечего

- H7 (share-price inflation в стейкинге USDh): слабость подтверждена, но цепочка кражи
  рушится на уровне VM — `mint(0)`/`transfer(0)` невозможны, жертва не может получить
  0 шеров, транзакция откатывается атомарно, средства целы. Лучший вариант атакующего
  даёт прибыль ровно 0 (проверено PoC, фаза P2b).
- Остаточная severity — Low (re-armable DoS/griefing, без потери средств). Программа
  Hermetica платит от High; активы USDh staking в видимом asset-list отсутствуют.
  Подача = отказ + репутационный урон. Рекомендация отчёта: **do not submit**.
